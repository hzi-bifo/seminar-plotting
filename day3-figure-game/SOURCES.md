## Scatterplot walkthrough

Five original versions generated by `generate_scatter_walkthrough.R` use the identical 1,600 synthetic single-cell measurements in `data/scatter-cells.csv` (seed 87). Protein fluorescence is expressed in arbitrary units. No points are removed or jittered; axis limits are fixed. Histogram bins are 5 units wide, and bar lengths count cells. Hollow points are shown as an alternative to alpha transparency, not a universally superior next step.

## Additional guided improvements

`generate_more_walkthroughs.R` produces original synthetic distribution, paired-donor, and heatmap examples, with CSVs. These are teaching illustrations, not published findings. Both violin groups use a Gaussian kernel with bandwidth 0.65 and the same density-to-width factor, trimmed to observed ranges. Horizontal dot jitter preserves signal measurements. The heatmap retains fixed −3 to +3 limits and identical log2 fold changes, using a manually chosen teaching order rather than inferred clusters. The paired-donor example includes five decreases and three increases; its final view explicitly plots after minus before.

### Scatter gallery design comparisons
Synthetic data generated by `generate_scatter_gallery.R` (seed 825), with CSVs in `data/gallery-scatter-*` and `data/gallery-pcoa-*`. PCoA uses Euclidean distances between square-root relative taxon counts (Hellinger distance), base R `cmdscale`, and equal axis scaling. Axis percentages use positive eigenvalues; this Euclidean construction has no substantive negative eigenvalues. Root/bulk differences were simulated for teaching and are not experimental evidence.
Method reference: [R stats: classical multidimensional scaling / principal coordinates analysis](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/cmdscale.html).

### Matched gallery repairs
`generate_gallery_repairs.R` uses the existing synthetic gallery CSVs and shared values for both versions of each plot. Newly defined time-course values are exported as `data/repair-line.csv`. Cell compositions and tracked-cell Sankey counts match the existing gallery datasets. Raincloud jitter is fixed by seed 1204. The PCA percentages (47.8%, 7.7%) are recorded from the original gallery fit; coordinates come from its exported CSV. `generate_logo_repair.py` reuses the original information-logo glyphs unchanged and alters only explanatory labels. Some starting versions deliberately omit essential keys, hide observations or use misleading spacing/scales. These are demonstration errors, not alternative analytic results.
